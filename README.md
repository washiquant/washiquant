## Projetos em Destaque

### 🚚 Controle de Entregas & Painel Analítico

Sistema completo para gestão de comandas, faturamento diário/semanal/mensal, integração com API REST externa e gráficos analíticos.

**Destaques de Engenharia:**
- Arquitetura em camadas (Frontend/Backend/Services) e persistência em SQLite.
- Consumo e validação da API do **ViaCEP** para preenchimento de endereço.
- Suíte de testes unitários com **Pytest**, banco em memória (`:memory:`) e **Mocks**.
- Visualização de dados via **Matplotlib** renderizado em Base64 no **Flet**.
- Containerizado com **Docker** e Docker Compose.

**Tecnologias:** `Python` | `Flet` | `SQLite` | `Pytest` | `ViaCEP API` | `Docker`
